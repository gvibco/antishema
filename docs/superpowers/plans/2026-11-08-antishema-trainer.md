# АнтиСхема — план реализации

> **Для исполнителя:** выполнять по порядку, отмечать шаги `[x]`.

**Цель:** статический сайт-тренажёр «АнтиСхема» и обновлённая презентация.

**Архитектура:** данные сценариев (`js/scenarios.js`) отделены от чистой
логики (`js/engine.js`) и DOM-слоя (`js/app.js`). Стили — `css/styles.css`.
Логика движка тестируется встроенным тест-раннером Node.js.

**Стек:** HTML5, CSS3, vanilla JavaScript, Node.js `node:test` для тестов.

## Глобальные ограничения

- Без сборки и внешних зависимостей.
- Работа через `file://`: классические скрипты, без ES-модулей.
- Русский язык интерфейса.
- Адаптив от 320 px, доступность с клавиатуры.
- Презентация: 10 слайдов, без тестирования на учениках и «Следующих шагов».
