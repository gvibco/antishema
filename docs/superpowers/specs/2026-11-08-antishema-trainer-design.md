# АнтиСхема — сайт-тренажёр: дизайн

**Дата:** 2026-11-08
**Проект:** учебный проект, 10 «И» класс, ГБОУ «Школа № 2127»
**Команда:** «Интернет-защитники»
**Авторы:** Посысаев Иван Сергеевич, Шульга Георгий

## Цель

Сделать интерактивный веб-тренажёр, который помогает школьникам 8–11 классов
распознавать интернет-мошенничество и выбирать безопасное действие в
подозрительном диалоге.

## Аудитория

Школьники 8–11 классов (14–17 лет), которые активно общаются в мессенджерах,
пользуются цифровыми сервисами и могут столкнуться с мошенниками в обычном
чате.

## Структура сайта

Две страницы:

**`index.html` — главная:**

1. Шапка с логотипом и навигацией.
2. Первый экран: название, суть проекта, кнопка перехода к тесту, статистика.
3. Блок «Как это работает»: ситуация → выбор → разбор.
4. Блок-приглашение пройти тест на отдельной странице.
5. Памятка «Красные флаги».
6. Блок «О проекте»: авторы, школа, цель, источники.
7. Подвал с пометкой о вымышленных сценариях.

**`trainer.html` — тренажёр:**

1. Шапка с навигацией и активным пунктом «Тренажёр».
2. Компактный первый экран с описанием теста.
3. Тренажёр: 6 заданий, прогресс, счёт, обратная связь.
4. Итоговый экран: результат, уровень, правила, повторное прохождение.
5. Ссылки «На главную» и «Открыть памятку».

## Механика тренажёра

- 6 сценариев: 4 диалога и 2 задания «распознай мошенничество».
- В диалоге показывается переписка и 2 варианта ответа.
- В задании-распознавании показывается сообщение и выбор «Безопасно» /
  «Похоже на мошенничество».
- После ответа: верно/неверно, объяснение, красный флаг и правило.
- Один правильный ответ на задание; счёт 0–6.
- В конце: процент, уровень, список правил, кнопка «Пройти ещё раз».
- Прогресс сохраняется в памяти вкладки; регистрация не нужна.

## Сценарии

1. «Сотрудник банка» просит код из СМС.
2. «Друг» просит деньги и секретность.
3. «Лёгкая подработка» требует предоплату за доступ.
4. «Покупатель» присылает фишинговую ссылку.
5. Распознавание: «родственник» с нового номера просит денег.
6. Распознавание: безопасное сообщение классного руководителя.

## Визуальный стиль

- Светлый, доверительный, без «хакерской» эстетики.
- Палитра: белый фон, глубокий синий, оранжевый акцент, зелёный/красный для
  обратной связи.
- Карточки с закруглениями, мягкие тени, интерфейс задания в виде мессенджера.
- Системный шрифт, без внешних зависимостей.
- Умеренные анимации, адаптив от 320 px, управление с клавиатуры,
  `aria-live` для обратной связи.

## Технические ограничения

- Чистые HTML, CSS и JavaScript без сборки.
- Сайт открывается двойным кликом по `index.html` (протокол `file://`).
- Никаких CDN, шрифтов и библиотек из интернета.
- Классические `<script>` вместо ES-модулей, чтобы работал `file://`.
- Логика движка отделена от DOM и покрыта тестами Node.js.
