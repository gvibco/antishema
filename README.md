# АнтиСхема

Интерактивный веб-тренажёр против интернет-мошенничества. Учебный проект
команды «Интернет-защитники», 10 «И» класс, ГБОУ «Школа № 2127».

**Авторы:** Посысаев Иван Сергеевич, Шульга Георгий.

**Сайт:** <https://gvibco.github.io/antishema-site/>  
**Репозиторий:** <https://github.com/gvibco/antishema> (private)  
**Публичная сборка для хостинга:** <https://github.com/gvibco/antishema-site>

## Быстрый запуск

Сайт не требует сборки и зависимостей:

1. Откройте `index.html` двойным кликом.
2. Нажмите «Пройти тест» — откроется отдельная страница `trainer.html`.

Для проверки через локальный сервер:

```powershell
py -m http.server 8765
```

Затем откройте <http://127.0.0.1:8765/index.html>.

## Что внутри

- 10 сценариев: 6 диалогов и 4 задания «распознай мошенничество».
- Разбор каждого ответа: объяснение, красный флаг и правило.
- Итоговый экран с результатом и повторным прохождением.
- Отдельная страница «Правила защиты» из 12 правил в четырёх категориях.
- Памятка из шести красных флагов и блок «Если уже обманули».
- Адаптивная вёрстка для телефона и компьютера.
- Работа без регистрации и без внешних библиотек.

## Структура

```text
index.html              главная страница
trainer.html            отдельная страница тренажёра
rules.html              страница из 12 правил защиты
css/styles.css          стили и адаптив
js/scenarios.js         содержание десяти сценариев
js/engine.js            чистая логика игры
js/trainer.js           отрисовка и обработка действий тренажёра
js/site.js              общая навигация для всех страниц
tests/                  тесты движка, сценариев и страницы правил
docs/presentation/      PDF и PNG-превью презентации
docs/screenshots/       скриншоты сайта
tools/                  сборка, нормализация и проверка презентации
```

## Страницы

- `index.html` — главная: описание проекта, принцип работы, памятка и авторы.
- `trainer.html` — сам тест: 10 заданий, разбор ответов и итоговый результат.
- `rules.html` — 12 правил защиты, красные флаги и действия, если обманули.

## Тесты

```powershell
node --test tests/engine.test.js tests/scenarios.test.js
```

Проверяются подсчёт очков, завершение игры, уровни результата, целостность
сценариев и наличие 12 правил на отдельной странице.

## Презентация

Файлы:

- `АнтиСхема_презентация_Посысаев_Иван_Шульга_Георгий.pptx` — редактируемая;
- `АнтиСхема_презентация_Посысаев_Иван_Шульга_Георгий.odp` — для LibreOffice;
- PDF и PNG-превью — в `docs/presentation/`.

Что изменено:

- 11 слайдов: добавлен слайд «Итоговые выводы»;
- дорожная карта переделана в диаграмму Ганта (сентябрь–ноябрь 2026);
- на слайде «Целевая аудитория» добавлено психологическое обоснование
  через когнитивный диссонанс;
- убраны номера слайдов и заметки с источниками;
- один шрифт (Arial) и три цвета: тёплый фон `#F7F3EA`, петроль `#123B3A`,
  терракота `#E4572E`;
- слайд «Следующие шаги» отсутствует.

Сборка:

```powershell
py tools/build_presentation.py

soffice --headless --convert-to odp --outdir . "АнтиСхема_презентация_Посысаев_Иван_Шульга_Георгий.pptx"
py tools/normalize_odp.py

soffice --headless --convert-to pdf --outdir docs/presentation "АнтиСхема_презентация_Посысаев_Иван_Шульга_Георгий.odp"
py tools/render_presentation.py
py tools/verify_presentation.py
```
