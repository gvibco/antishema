# АнтиСхема

Интерактивный веб-тренажёр против интернет-мошенничества. Учебный проект
команды «Интернет-защитники», 10 «И» класс, ГБОУ «Школа № 2127».

**Авторы:** Посысаев Иван Сергеевич, Шульга Георгий.

## Быстрый запуск

Сайт не требует сборки и зависимостей:

1. Откройте `index.html` двойным кликом.
2. Нажмите «Пройти тест» — откроется отдельная страница `trainer.html`.

Для проверки через локальный сервер:

```powershell
py -m http.server 8765
```

Затем откройте <http://127.0.0.1:8765/index.html>.

## Что внутри

- 6 сценариев: 4 диалога и 2 задания «распознай мошенничество».
- Разбор каждого ответа: объяснение, красный флаг и правило.
- Итоговый экран с результатом и повторным прохождением.
- Памятка из шести красных флагов.
- Адаптивная вёрстка для телефона и компьютера.
- Работа без регистрации и без внешних библиотек.

## Структура

```text
index.html              главная страница
trainer.html            отдельная страница тренажёра
css/styles.css          стили и адаптив
js/scenarios.js         содержание шести сценариев
js/engine.js            чистая логика игры
js/trainer.js           отрисовка и обработка действий тренажёра
js/site.js              общая навигация для обеих страниц
tests/                  тесты движка и сценариев
docs/presentation/      PDF и PNG-превью обновлённой презентации
docs/screenshots/       скриншоты сайта
tools/                  скрипты сборки и проверки презентации
```

## Страницы

- `index.html` — главная: описание проекта, принцип работы, памятка и авторы.
- `trainer.html` — сам тест: 6 заданий, разбор ответов и итоговый результат.

## Тесты

```powershell
node --test tests/engine.test.js tests/scenarios.test.js
```

Проверяются подсчёт очков, завершение игры, уровни результата и целостность
сценариев.
